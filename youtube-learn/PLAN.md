# 클립러닝 (ClipLearn) 기획서

> 유튜브 영상 하나를 넣으면, 그 내용을 분석해서 **관련 지식을 짧은 시간에 익힐 수 있는 학습 코스**로 바꿔 주는 앱

---

## 1. 문제 정의

| 지금의 불편 | 원인 |
|---|---|
| 30분짜리 강의 영상을 보고도 남는 게 없다 | 수동적 시청, 복습·인출(떠올리기) 과정이 없음 |
| 영상 속 용어를 몰라 중간에 막힌다 | 사전지식 확인 없이 바로 본론 |
| "더 공부하려면 뭘 봐야 하지?"가 막막하다 | 다음 학습 경로가 제시되지 않음 |
| 요약 툴은 요약만 해 준다 | 요약 ≠ 학습. 이해 확인·암기 도구가 빠져 있음 |

**핵심 가설**: 영상 내용을 *요약 → 개념 → 짧은 레슨 → 퀴즈/플래시카드 → 관련 주제*로 재구성하면, 같은 시간 안에 이해도와 기억 유지율이 크게 오른다.

## 2. 타깃 사용자

1. **자기계발 학습자** – 경제·IT·과학 유튜브로 공부하는 직장인 (출퇴근 15분)
2. **학생/수험생** – 인강·강의 영상 복습
3. **실무자** – 컨퍼런스 발표, 기술 튜토리얼을 빠르게 흡수하고 싶은 개발자·기획자

## 3. 핵심 사용 흐름

```
[유튜브 링크 입력] ─┬─ (권장) 스크립트 붙여넣기
                   └─ (자동) 링크만 → AI가 웹에서 영상 정보 조사
        │
        ▼
[학습 설정]  수준: 입문 / 중급 / 고급   ·   목표 시간: 5 / 15 / 30분
        │
        ▼
[AI 분석]  한 줄 요약 · 핵심 요약 · 챕터 타임라인 · 핵심 개념
        │
        ▼
[빠른 학습 코스]
   ① 학습 경로 (단계별 미니 레슨 + 단계마다 확인 질문)
   ② 플래시카드 (알아요/다시 보기 → 모르는 카드만 반복)
   ③ 퀴즈 (객관식 + 해설, 점수)
   ④ AI 튜터 Q&A (영상 내용 기반 질문)
   ⑤ 관련 주제 & 다음에 볼 검색어
        │
        ▼
[보관함]  분석한 영상 목록 저장, 다시 열어 복습
```

## 4. 기능 명세

### MVP (이번에 구현)

| # | 기능 | 설명 |
|---|---|---|
| F1 | 영상 입력 | 유튜브 URL 파싱(watch / youtu.be / shorts / embed), 플레이어 임베드 |
| F2 | 스크립트 입력 | YouTube "스크립트 표시" 내용 붙여넣기. 타임스탬프 유지 |
| F3 | 링크만 분석 | 스크립트가 없으면 웹 검색·웹 페이지 조회 도구로 영상 정보를 조사해 분석 (정확도 낮음 안내) |
| F4 | 학습 설정 | 수준·목표 시간에 맞춰 레슨 분량/난이도 조절 |
| F5 | 요약 & 챕터 | 한 줄 요약, 핵심 포인트, 타임스탬프 챕터 (클릭 시 해당 시점 재생) |
| F6 | 핵심 개념 | 용어 + 쉬운 설명 + 비유 |
| F7 | 학습 경로 | 단계별 미니 레슨, 각 단계 확인 질문, 진행률 |
| F8 | 플래시카드 | 뒤집기, "알아요/다시" 분류, 모르는 카드만 다시 돌리기 |
| F9 | 퀴즈 | 객관식, 즉시 채점과 해설, 최종 점수 |
| F10 | AI 튜터 | 영상 내용을 근거로 답하는 질의응답 (스트리밍 응답) |
| F11 | 관련 학습 | 이어서 공부할 주제, 이유, 유튜브 검색 링크 |
| F12 | 주의할 점 | 영상 속 주장 중 확인이 필요하거나 논쟁적인 부분 표시 |
| F13 | 보관함 | 분석 결과를 브라우저에 저장, 다시 열기/삭제 |
| F14 | 데모 모드 | API 키 없이 예시 데이터로 전체 흐름 체험 |

### 다음 단계 (v2 이후)

- ✅ **자막 자동 추출 + 음성 인식 서버** (`server/`): 유튜브 자막을 먼저 가져오고, 없으면 오디오를 OpenAI 음성 인식으로 받아 적음. API 키는 서버에 보관, 공개 배포용 접속 암호 지원
- **로그인과 사용량 제한**: 여러 사용자에게 서비스할 때 계정별 사용량·비용 관리
- **간격 반복(SRS)**: 플래시카드를 1일·3일·7일 후 다시 알림
- **재생목록 단위 코스**: 여러 영상을 묶어 하나의 커리큘럼 생성
- **영상 구간 퀴즈**: 시청 중 챕터가 끝날 때마다 문제 팝업
- **노트 내보내기**: Notion / Markdown / Anki 덱 내보내기
- **학습 통계**: 연속 학습일, 정답률, 약한 개념

## 5. 화면 구성

1. **홈 / 입력**: URL 입력창, 스크립트 붙여넣기(접이식, 방법 안내 포함), 수준·시간 선택, [분석 시작], [데모 보기]
2. **결과 – 상단**: 영상 플레이어 + 제목·한 줄 요약·난이도·예상 학습 시간
3. **결과 – 탭**: 요약 | 개념 | 학습 경로 | 플래시카드 | 퀴즈 | 튜터 | 관련 학습
4. **보관함**: 카드 목록(제목, 날짜, 퀴즈 점수)
5. **설정**: Claude API 키 입력·삭제

## 6. 기술 설계

| 항목 | 선택 | 이유 |
|---|---|---|
| 형태 | 단일 `index.html` (설치·빌드 없음) | 이 저장소의 기존 앱(`tarot/`)과 같은 방식, 바로 열어서 사용 |
| AI | Claude API, 공식 SDK `@anthropic-ai/sdk` (브라우저 ESM, jsDelivr) | |
| 모델 | `claude-opus-5-5`, adaptive thinking, effort `medium` | 분석 품질과 속도의 균형 |
| 구조화 출력 | `output_config.format` (JSON Schema) | 탭마다 렌더링할 데이터를 항상 같은 형태로 받음 |
| 스트리밍 | `messages.stream()` → `finalMessage()` | 긴 스크립트·긴 출력에서 타임아웃 방지, 튜터 답변은 글자 단위 표시 |
| 링크만 분석 | 서버 도구 `web_search_20260209`, `web_fetch_20260209` | 스크립트 없이도 영상 정보 조사 |
| 거절 대응 | 서버 측 fallback (`fallbacks: "default"`) | 안전 분류기가 요청을 거절하면 다른 모델로 자동 재시도 |
| 저장 | `localStorage` (보관함, 설정) | 서버 없이 동작 |
| 보안 | 모델 출력은 모두 `textContent`로 렌더링 | 출력에 HTML이 섞여도 실행되지 않음 |

### AI 출력 스키마 (요약)

```
title, one_liner, difficulty(입문|중급|고급), estimated_minutes,
summary[], chapters[{time, title, gist}], concepts[{term, explanation, analogy}],
lesson_path[{step_title, minutes, content, check_question, check_answer}],
flashcards[{front, back}], quiz[{question, choices[], answer_index, explanation}],
related[{topic, why, search_query}], caveats[]
```

## 7. 성공 지표

- 분석 완료율 (입력 → 결과 표시)
- 퀴즈 평균 정답률, 플래시카드 "알아요" 비율
- 영상 1개당 학습 시간 (목표 시간 대비)
- 7일 내 보관함 재방문율

## 8. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 자막을 자동으로 못 가져옴 | MVP는 붙여넣기 + 링크만 분석, v2에서 자막 서버 |
| 링크만 분석 시 내용 부정확 | 결과 상단에 "스크립트 없이 분석됨" 배지, 스크립트 붙여넣기 권장 |
| 영상 속 잘못된 정보 학습 | "주의할 점" 섹션으로 검증 필요한 주장 표시 |
| 브라우저에 API 키 저장 | 개인용 MVP로 한정, 서비스화 시 서버 프록시 |
| 긴 영상(2시간+) 비용 | 예상 비용 안내, v2에서 챕터 단위 분석 |
